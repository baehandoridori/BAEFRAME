# AI 작업 지침 정리

## 목적과 범위

사용자가 문서별 점검 결과와 시각적 수정안을 확인한 뒤 수정을 승인했다. 앱 동작 변경 없이 Codex·Claude Code의 공통 규칙, 현재 기능 상태, 검증·배포 절차를 정리했다. 점검 기준은 `85fd0c2`, `2.9.0-beta`다.

## 개인 스킬 반영 (이 저장소 Git에 포함되지 않음)

사용자 홈의 `.agents/skills/`와 `.claude/skills/` 양쪽에서 다음을 수정했다.

- `baeframe-release-deploy/SKILL.md`: 저장소 릴리스 가이드 연결, 무응답 통과 제거, 빌드 명령 통일, 전체 배포 검증. 양쪽 내용 동일.
- `codex-review-loop/SKILL.md`: 최종 head SHA·리뷰 봇·트리거 일치 확인, 대상 저장소별 테스트·배포 가이드 선택. 도구별 watcher 경로 안내는 유지.

개인 스킬은 다른 PC로 Git만 받아서는 전달되지 않는다. 해당 PC에서도 저장소 가이드로 연결해야 한다. 자동 리뷰 watcher 스크립트 자체는 변경하지 않았으며, 스킬의 최종 SHA 판정은 에이전트가 별도로 확인한다.

## 검증

- 새 공통 문서·CLAUDE.md·현재 기능표의 로컬 Markdown 링크 35개: 대상 파일 존재 확인.
- 문서에 안내한 npm script 이름: 현재 package.json과 대조, 미등록 항목 없음.
- UI 스킬 검색 명령의 `--help`: 종료 코드 0.
- `git diff --check`: 통과.
- 두 개인 배포 스킬 SHA-256 일치 확인.
- 문서 변경만 수행했으므로 앱 테스트·빌드·실기 검증은 재실행하지 않았다. 기존 DEVLOG의 테스트 수치를 이번 결과로 재사용하지 않았다.

## 남은 범위

초기 수정은 문서에 한정했고, 후속 요청으로 커밋·PR·리뷰·머지·재빌드·배포·완료된 worktree 정리가 승인되었다. 앱 기능 변경이 없어 버전은 2.9.0-beta를 유지한다. 과거 문서에 남은 미지원 기능과 현재 구현을 구분했으며 새 기능을 구현하지 않았다.
