# 코멘트 입력과 실행 버전 일관성 수정

## 범위와 실행 경계
- 최신 배포 2.12.5-beta / `9a36b8593b30970784cbb1cf04f402123768ff1b`에서 별도 worktree로 진행한다.
- 사용자 요청에 따라 앱 실행·재시작·화면/마우스/키보드 조작 없이 Node/jsdom 검증, 빌드, 배포 파일 검증만 수행한다.
- 온라인 Codex 리뷰는 한도 소진으로 사용하지 않고 독립 내부 코드 리뷰를 진행한다.

## 확인한 원인
1. 확대·중앙 고정 해제 상태에서는 `canPanVideo()`가 코멘트 모드에도 primary pointer를 캡처하여 마커 클릭이 영상 이동으로 전달된다.
2. C 진입이 mpv → HTML5 파일 재로딩을 먼저 시도한다. 기존 freeze 방식으로 입력을 준비할 수 있는데도 엔진 교체가 지연과 화면 전환을 일으킨다. CSS의 중앙 십자선은 실제 선택 위치와 무관하다.
3. 영상 위 pending marker textarea에는 이미지 paste 이벤트가 없고 전역 붙여넣기는 textarea를 제외한다. 사이드바와 다른 동작이다.
4. 프로필 누락과 이전 PC 재생 설정이 구형 도구로 내려가는 경로가 있다. 개발 실행이 파일 연결/프로토콜 등록을 덮을 수 있고 백업 실행 방지 정책이 없다.

## 수정·검증 계획
- 코멘트/드로잉의 일반 클릭과 Space 이동을 분리하고 확대 좌표·준비 중·비동기 영상 변경 경계를 실제 함수로 검증한다.
- 코멘트는 현재 재생 엔진의 준비된 정지 화면을 사용한다. 중앙 장식 대신 실제 마우스 위치의 crosshair cursor를 사용한다.
- pending marker 이미지 paste·미리보기·삭제와 비동기 취소 경계를 추가한다. 기존 저장 포맷은 유지한다.
- 현재 드로잉을 기본 경로로 고정하고 구형 도구로의 자동 전환을 제거한다. 기존 그림 데이터 읽기 호환성은 보존한다.
- 정상 배포 실행만 파일 연결을 갱신하도록 제한하고 백업·staging 실행은 차단/정상 위치로 연결한다. 기존 백업도 배포 단계에서 실행 불가능한 보관 형태로 정리한다.
- 관련 Node 테스트 → 내부 독립 리뷰 → 최종 SHA 검증 → PR/머지 → 정확한 merge SHA 빌드 → staging/백업/공유드라이브 전체 SHA 검증 순서로 진행한다.

## 진행
- 의존성 설치: `npm ci --no-audit --no-fund`, 종료 코드 0.
- 사용자 앱/네이티브 E2E는 수행하지 않는다. 다른 PC의 증상과 공유드라이브 동기화 완료는 별도 미확인 범위다.

## 구현 및 회귀 검증
- 코멘트 배치: 변환된 영상 rect를 사용하고, Space 패닝·준비 중·비유효 좌표를 차단한다. 비동기 cutlist 준비 중 모드/영상/의도가 바뀌거나 다음 클릭이 오면 늦은 결과를 버린다.
- 코멘트 진입: 엔진 재로딩 대신 `VideoPlayer.pauseAndSync()`로 정지 응답 및 최종 프레임을 확인한다. 내부 리뷰에서 발견한 정지 프레임 경합(P2)을 수정했다. 정지 확인 중 발생하는 frameUpdate도 같은 진입 소유권으로 다뤄 조기 캡처를 막는다.
- 영상 위 이미지 입력: 실제 Clipboard Blob(items/files) 수집, pending 마커 미리보기·삭제·이미지 단독 확인, 마지막 요청만 반영한다. 변환 중 Enter나 취소/영상 변경 후 완료도 방어한다.
- 실행 정책: 현재 기능을 기본 사용하고 이전 PC 설정을 정리한다. 구형 드로잉 활성화 경로를 차단하되 기존 데이터 읽기는 보존한다. 백업 실행의 정상 경로 검증과 개발 실행의 파일 연결 등록 차단을 추가했다.
- 수정 전 재현: 코멘트 배치 8개 중 6 fail, 현재 드로잉 정책 6개 중 4 fail, 이미지 27개 중 16 fail. 해당 결함을 고친 뒤 관련 검사는 통과했다.
- 회귀 검사 84개 파일: **2,057 pass / 0 fail / 0 cancelled / exit 0**. mpv, 코멘트/분리창, UX, Fabric, 재생목록, 버전, 드로잉 데이터, 패닝, FPS 포함. 화면을 여는 `mpv-native-window` 및 `mpv-fabric-overlay-toolbar-layout` 두 검사는 명시적으로 제외했다.
- 변경 파일 ESLint `--no-ignore`: 오류 0, 기존 미사용 변수 등 경고 28, exit 0. `git diff --check` 통과.
- 마지막 재생 상태 코드 정리 후 관련 검사 **164 pass / 0 fail / 0 cancelled / exit 0**. 실행/백업 정책은 **24 pass / 0 fail / 0 cancelled / exit 0**이며 임시 파일을 사용한 PowerShell 보관·롤백 검사 7개가 포함된다.
- 독립 내부 리뷰: main 실행/등록 정책 및 renderer 입력/재생 경계 검토 완료, P2 1건 수정 후 미해결 0건. 최종 SHA 리뷰·빌드·배포 증거는 배포 보고서에 기록한다.
