## 배경 및 목적

2026-08-25 22:59 배포본에서 사용자가 보고한 8항목은 서로 다른 증상처럼 보였지만, 실측 결과 **뿌리가 셋**이었다.

1. **저장 실패 래치 하나가 소유권·표시·입력을 동시에 지배** — `legacyBypass` 불리언이 `shouldOwnDrawingShortcut()`의 조건항이라, 저장이라는 데이터 계층 사건이 타임라인 투영·CSS 마스크·B 라우팅을 한 번에 레거시로 되돌렸다. 2026-08-27 로그의 `invalid-persistence-snapshot`(blocked:true) 2건이 이 경로를 그대로 재현한다.
2. **차단 조건이 대상·키의 실제 소비 여부와 분리** — 문자 키를 소비하지 않는 슬라이더·셀렉트를 텍스트 입력과 동일 취급하고, 편집 대상이 없어도 IME 플래그만으로 전체 단축키를 폐기하며, 오버레이에서 릴레이된 키를 남아 있던 텍스트 포커스에 되꽂았다.
3. **일시 실패와 구조 손상을 같은 사유로 뭉갬** — 오버레이가 한 프레임 늦게 응답한 정상 상황이 영구 저장 차단 + 레거시 후퇴로 승격됐다.

## Phase 1: PR ① — 핵심 고장 (작업 1·2·3·4·6)

### 목표
증상 1·2·3·4·6을 한 번에 배포 가능 상태로. 작업 1이 나머지의 기반이므로 최우선.

### 구현 내용

**작업 1** — `shouldOwnDrawingShortcut()`에서 `legacyBypass` 참조 제거. `setPersistenceBypass()`의 세션 강제 종료(`desiredInputEnabled`/`resumeRequested`/`currentSession`/`setState('passive')`)를 `blocked === true` 분기 안으로 한정하되, `persistenceBoundSourceEpoch = null`은 저장 계층 장치이므로 분기 밖 유지. 스냅샷에 `persistenceDegraded` 별칭, 공개 API에 `clearPersistenceSaveBlock` 추가.

**작업 2** — `toggleDrawMode` 라우팅을 mpv 기준으로 고정. 가드 축을 `getState()`로 세운 것이 핵심이다 — 작업 1 이후 `shouldOwnDrawingShortcut() ≡ isEnabled()`가 되어 `if (isEnabled()) { if (!shouldOwnDrawingShortcut()) {…} }` 형태의 중첩 가드는 도달 불가능한 죽은 코드가 된다. `getFabricPilotTimelineLayers`가 레거시 `drawings`를 `pilotProjected` 읽기 전용 행으로 함께 투영하고, store 미수화 시에도 `null`을 반환하지 않는다.

**작업 3** — `consumePendingResumeRequest()` 예약 소비 단일 함수를 도입하고 정착 지점 5곳에 배선. 반환값 3분기(`null`/`false`/`Promise`)로 기존 호출부 반환 계약을 유지했다. `setDrawingInput`의 disable 반환 3경로 전부에서 `moveTop`/`invalidate`를 복원하고, 진단 restack 계약을 `Math.max(0, toggleCount-1)` → `toggleCount` 완전일치로 조였다.

**작업 4** — 비텍스트 폼 컨트롤이 실제로 소비하는 10개 코드만 차단, IME 조합 게이트를 텍스트 입력 대상에만 적용. 방화벽에서 `drawMode`를 `KeyE`·chord 차단보다 **먼저** 예외 처리하고, Ctrl chord 차단에 `event.code` 기반 조건을 OR로 더해 IME `key === 'Process'` 우회를 막았다. 호스트의 하드코딩 `'KeyB'`를 렌더러가 상태 sync로 보내는 서술자로 대체. 고아 테스트 `keyboard-shortcut-targets.test.js`를 `test:mpv`에 등록.

**작업 6** — 요청-스냅샷 펜스 불일치를 `stale-drawing-snapshot`으로 분리(비래치), 구조 위반만 `invalid-persistence-snapshot` + 차단 래치. IPC 데드라인 3000 → 8000ms. `ReviewDataManager`에 `saveStateChanged` 이벤트와 2s→5s→10s 지수 백오프. 헤더 저장 상태 칩 추가, 실패 토스트를 재시도 소진 후로 이동.

`scripts/tests/fabric-drawing-pilot-source.test.js:302`의 `assert.doesNotMatch(appSource, /fabricDrawingPilotController\.(?:getStatusSnapshot|diagnostics)\(\)/)`는 **app.js 소스 텍스트 전체**를 검사하는 HUD 폴링 금지 불변식이다. 정규식은 코드와 주석을 구분하지 않으므로, 그 리터럴을 주석에 적기만 해도 단언이 깨진다. 계획서는 두 곳 모두 "캐시 참조를 지킨 상태에서는 통과"라고 명시하고 있었으므로, **단언을 완화하는 대신 주석 표현만 바꿔 불변식을 살리는 쪽**을 택했다. 실제 코드는 계획서 의도대로 캐시 변수 `fabricDrawingPilotStatusSnapshot`을 읽는다.
