# 그리기 팔레트 UI 깨짐 5건 (PR #206)

- 브랜치: `claude/드로잉-팔레트-ui수정` → main (`8ffa4f7`)
- 버전: 2.6.1-beta
- 코덱스 리뷰: 3라운드 (P1 1 / P2 1), 마지막 신호 `Didn't find any major issues` (`ae61727a9f`)
- 검증: 25개 스위트 2,283 pass / 0 fail, Electron 레이아웃 2 pass
- 배포: 공유 드라이브 `테스트버전 빌드`, 82파일 해시 `MismatchCount=0`

## 근본 원인은 하나

**JS 가 클래스를 붙이는데 CSS 규칙이 어디에도 없었다.** 팔레트 CSS 는
`main/mpv-overlay-host.js` 에 문자열로 들어 있고, `.mpv-fabric-pilot-brush-status`
와 `-eraser-mode` 는 거기에 없었다. 그래서 브라우저 기본값(`display: block`,
`font-size: 16px`)으로 떨어졌다.

클래스 **이름은 제대로 붙어 있으므로** 런타임 테스트는 이걸 잡을 수 없다.
DOM 을 조회하는 테스트는 전부 통과한다 — 깨지는 것은 계산된 스타일뿐이다.

## 고친 것

| # | 증상 | 원인 |
|---|---|---|
| 1 | 상태 줄이 팔레트에서 가장 큰 글자, 3px 견본이 마침표로 읽힘 | `.mpv-fabric-pilot-brush-status` CSS 없음 |
| 2 | 픽셀·획 버튼이 간격 없이 맞붙음 | `.mpv-fabric-pilot-eraser-mode` CSS 없음 |
| 3 | 팔레트 스크롤 **안에 또** 스크롤, 외곽선 설정에 닿을 수 없음 | 패널을 210px 로 자르는데 내용은 531px |
| 4 | 색 견본 8개가 네 줄 | 기본 버튼 패딩 `0 12px` 이 22px 점에 더해져 46px |
| 5 | 슬라이더 줄이 **세 줄로 쪼개짐** | range 입력 `flex-basis: auto` 가 크로뮴 기본 폭 129px 예약 |

3·5 는 210px 컷 아래 가려져 있던 기존 결함이고, 컷을 걷어 내며 드러났다.
패널 높이 **531px → 303px**.

캐럿: 도형 버튼 드롭다운 캐럿이 2px 만 들여 있어 바깥 꼭짓점이 모서리 반경 8px 호
**밖**으로 나갔다(중심에서 √72≈8.49 > 8). 4px 이면 √32≈5.66 < 8 이라 면 안에 앉는다.

## 치수는 인라인으로 주지 말 것 (코덱스 2차)

색 견본을 인라인 36px 로 고정했더니 화면 ≤800px 에서 미디어 쿼리가 팔레트를
190px 로 줄여도 그 값을 이길 수 없었다. 패널 안쪽 약 156px 에 4*36 + 3*4 = 156 을
넘겨 3/3/2 로 흘렀다.

**미디어 쿼리가 책임져야 하는 치수는 CSS 에 둔다.** 넓은 폭 36px,
≤800px 32px(4*32 + 3*4 = 140). 간격도 `var(--fabric-palette-gap)` 로 연동했다.

## 테스트

되돌려 실패하는 것을 **다섯 건 모두 확인**했다.

- `mpv-fabric-overlay-toolbar-layout.test.js` — Electron 실기 프로브에 패널 실측
  단언 추가: 높이 컷 없음 · 안쪽 스크롤 없음 · 색 4개/줄 · 슬라이더 줄 한 줄 ·
  상태 줄 flex 11px. **800px 와 801px 두 폭에서 각각** 건다.
  미디어 쿼리가 바꾸는 치수를 한쪽에서만 재면 반대쪽이 통째로 사각지대다
  (초판이 801px 만 재서 4번 결함을 놓쳤고 코덱스가 잡아냈다).
- `fabric-drawing-pilot-source.test.js` — 신설 가드: 팔레트가 붙이는 모든 클래스는
  호스트 CSS 규칙이 있거나 인라인 `setStyles` 로 배치를 지정해야 한다.
  되돌리면 깨졌던 클래스 3개를 정확히 지목한다.
