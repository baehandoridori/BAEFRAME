## 추가 요청: 기본 켜짐 체크박스와 2.12.3-beta 배포

- 댓글 필터 줄 오른쪽에 작은 `자동 스크롤` 체크박스를 추가한다. 좁은 패널에서는 자연스럽게 줄바꿈한다.
- 처음 사용하는 경우와 기존 설정에는 기본 켜짐을 적용한다. 사용자가 끈 값은 개인 설정에 저장한다.
- 체크를 꺼도 재생 구간 강조는 유지하며, 다시 켜면 같은 재생 위치에서도 자동 이동이 재개된다.
- 현재 댓글, 분리한 댓글 패널과 이전 리뷰 팝업에 같은 설정을 전달한다.
- 300/380/500px 실제 댓글 패널 마크업과 제품 CSS를 headless Chromium에서 검사했다. 체크박스 넘침 없음, 기본값, 끄기, 새로고침 후 끈 상태 복원, 다시 켜기 모두 통과했다.
- 실제 앱을 화면에 띄우지 않는 조건을 유지하며 리뷰·머지·정확한 merge SHA 빌드·배포 파일 전체 검증을 진행한다. 아래 초기 검증 기록의 미배포 상태는 최초 수정 시점의 기록이다.

- 같은 프레임에서 숨김 해제/접힘 해제, 표시 크기 변경 중 재생 이벤트, 숨김 중 끄기 회귀 검증을 추가했다.
