## 사용자가 달라지는 점 (직전 합쳐 보기 단순화 구현)

1. 저장된 이전 리뷰가 있으면 **이전 리뷰 확인하기** 버튼을 표시한다. 같은 버튼으로 켜고 끈다.
2. 버전을 선택하면 현재 댓글과 **시간순으로 합쳐 표시**한다. 배지는 **v3**처럼 버전만 표시하며 분리/팝업 보기 선택은 없다.
3. **리뷰 N개 이어받기** 또는 개별 **이어받기**로 가져온다. 원래의 미해결·해결 상태를 유지하며 가져온 뒤 같은 두 상태로 변경한다. 확인 전/반영 확인/추가 수정과 별도 확인 목록은 제거했다.
4. 이어받은 리뷰는 같은 원문 대신 한 번만 표시한다. 버전 선택을 해제해도 남고, 토글을 껐다 켜도 유지된다. 원본 파일의 댓글 상태는 바꾸지 않는다.
5. 리뷰 본문이나 시간 버튼을 누르면 현재 영상의 해당 시간으로 이동한다. 원본 FPS를 현재 FPS로 환산하며, 영상 길이 밖이거나 시간 정보가 없으면 이동하지 않는다. 답글/첨부 펼치기·해결·이어받기 버튼은 재생 위치를 바꾸지 않는다.
6. 미해결·해결 필터와 검색, 댓글 개수/완료율에 표시 중인 이전 리뷰도 포함한다. 답글과 안전한 이미지 첨부는 그대로 읽을 수 있다.

## 최초 구현 기록 (아래의 별도 검수/팝업 설명은 단순화 이전 이력)

## 저장과 협업 처리

- `.bframe` 선택 루트 필드 `reviewCarryoverV1`에 현재 버전의 검수 결과와 읽기 시점 원문 snapshot을 저장한다. 원본 선택을 해제하거나 원본 파일이 사라져도 이어받은 내용은 남는다.
- 원본 영상 경로 + 원본 댓글 ID로 중복을 막는다. 취소 기록과 재추가 세대를 보존해 오래된 파일이 취소한 항목을 다시 살리지 않게 한다.
- 원본 reviewDocumentId는 출처 정보다. 같은 ID를 복제한 버전 파일을 서로 혼동하지 않도록 경로를 식별에 포함한다.
- 원본 상태와 별개인 검수 상태, 마지막 변경자·시간을 기록한다. 확인 목록은 저장·재로드 후에도 시간순으로 표시한다.
- 기존 저장 CAS와 파일 감시/3-way 병합 경로에 연결했다. 별도의 Liveblocks 이벤트는 추가하지 않았다. 여러 PC의 즉시 전달은 기존 파일 감시·드라이브 반영 속도를 따른다.
- 미지원/손상된 새 필드는 원형을 보존하고 편집을 차단한다. 매니저 없는 호출자의 외부 병합 후 저장에서도 보존한다. 기존 drawingsV3/레거시 드로잉 형식은 변경하지 않았다.

## 검토에서 수정한 문제

- 외부 파일을 읽는 동안의 검수 변경이 dirty에서 빠지는 문제: carryover 사용자 변경은 읽기 중에도 기록하고 소유 문맥의 자동 저장을 재예약한다.
- 매니저 없는 호출자의 병합된 payload 유실: 원격 기준선과 별도로 fallback을 보관한다.
- 영상 전환 최종 저장 뒤의 입력 유실: 저장 전에 토큰으로 입력을 잠그고, 오래된 전환은 토큰을 획득할 수 없게 한다. 취소 시 현재 소유자만 해제한다.
- 이미지 안전 검사 불일치: 공유 검사 함수를 재사용해 JPG/AVIF도 원문과 검수 목록에 표시한다.
- 숨긴 팝업의 오래된 DOM, 시간 없는 댓글의 0초 오인, 저장 후 항목 순서 변경을 수정했다.

사양/저장 리뷰와 UI/전체 통합 리뷰 후 P1/P2 지적을 모두 해소했다. 마지막 시간순 정렬 보완도 실제 모듈 회귀 테스트로 확인했다.

## 시연 후 버튼 표시와 토글 개선 (2026-09-08)

사용자 요청: 이전 버전에 리뷰가 있을 때만 진입 버튼을 표시하고 같은 버튼으로 켜고 끄기.

- 댓글 필터 아래에 **이전 리뷰 확인하기 · 꺼짐/켜짐** 텍스트 버튼을 배치했다. 켜짐은 노란색으로 표시하고 `aria-pressed`와 `aria-expanded`를 함께 갱신한다.
- 같은 영상의 다른 버전 `.bframe`을 읽어 실제 댓글이 있는지 확인한다. 현재 버전만 있거나, 파일이 없거나, 댓글이 비어 있거나 삭제된 댓글만 있으면 숨긴다. 해결된 원본도 반영 확인 대상이므로 버튼을 표시한다.
- 꺼짐은 원문·이번 버전 확인 목록·별도 팝업을 모두 접는다. 다시 켜면 선택 버전과 검수 상태를 유지한다. 원본 파일을 찾지 못하더라도 이미 이어받아 저장된 원문이 있으면 해당 확인 목록에 접근할 수 있다.
- 버전 목록별로 존재 확인을 재사용해 매 댓글 렌더마다 파일을 읽지 않는다. 버전 스캔/수동 추가·제거와 앱 포커스 복귀 시 재확인한다. 파일 전환 후 늦게 도착한 읽기 결과는 무시한다.
- 실제 모듈의 브라우저 시연 페이지에도 같은 버튼과 동작을 연결했다.
