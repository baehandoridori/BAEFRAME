# 크기·불투명도 줄을 목업의 필드 구성으로 (PR #210)

- 브랜치: `claude/드로잉-후속6` → main (`9e1b302`)
- 버전: 2.6.3-beta
- 코덱스 리뷰: 2라운드 (P2 1건 — **전제를 측정해 반박**), 마지막 신호 `Didn't find any major issues` (`0001d05e06`)
- 검증: 25개 스위트 2,285 pass / 0 fail, Electron 레이아웃 2 pass
- 배포: 공유 드라이브 `테스트버전 빌드`, 82파일 해시 `MismatchCount=0`

## 사용자 지적

"브러시 크기, 불투명도 버튼이 너무 멍청하게 큰 거 같은데, 목업처럼은 못 해?"

맞다. 40px 짜리 `-`/`+` 버튼 둘이 3px 트랙 양옆에 붙어 있으면 정작 조절하는
트랙보다 버튼이 커 보인다.

## 목업 사양 (§0.3 시안, artifact `99a13417`)

```
라벨(10px 대문자 자간)  ·····························  수치(11px 등폭)
──────────── 3px 트랙 + 9px 원형 손잡이 ────────────
```

목업에는 `-`/`+` 버튼이 **없다.** 걷어냈다.

- range 입력을 목업 트랙 모양으로 다시 그린다. 기본 렌더는 OS 위젯이라 팔레트와
  따로 논다 — **오버레이가 `main.css` 를 안 불러온다**는 직전 라운드와 같은 뿌리다.
- range 입력은 기본으로 **채운 부분을 그리지 않는다.** 값 비율을
  `--fabric-range-fill` 로 넘겨 트랙 배경 그러데이션의 경계로 쓴다.
  실측: 채움 `#a8a8a8` / 빈칸 `#424242`.
- 라벨을 `브러시 크기`→`크기` 등으로 줄였다. 섹션 이름이 이미 `브러시 설정`이라
  접두어가 중복이었다.

패널 높이 **303px → 253px**.

## 잃은 것

클릭 한 번에 ±1 씩 옮기던 수단. `[` / `]` 단축키와 Alt 드래그가 그대로 있고,
range 입력도 `step=1` 이라 트랙을 클릭하면 정수 값으로 바로 간다.

## 코덱스 P2 — 전제가 틀렸다

"버튼을 지웠으니 슬라이더를 탭 순서에 넣어라."

**이 창에서는 성립하지 않는다.** 그리기 입력이 켜져 있는 동안 호스트의
`before-input-event` 가 `FORWARDED_NAMED_KEY_CODES` 의 키를 메인 창으로 릴레이하고
**`preventDefault()` 한다.** 그 목록에 `Tab`·`Enter`·`Space`·`ArrowLeft`·
`ArrowRight` 가 모두 들어 있다(`main/mpv-overlay-host.js:1904-1920`, `4592-`).

- `Tab` 으로는 오버레이 안 **어떤** 컨트롤에도 갈 수 없다. 지운 `-`/`+` 버튼도
  마찬가지였다 — 키보드로 조작할 수 있었던 적이 없다.
- 슬라이더가 포커스를 얻어도 방향키가 소모돼 값이 바뀌지 않는다.

`tabindex` 를 달면 조작할 수 있다는 **거짓 표시**만 남는다. `tabIndex = -1` 이
정직한 표시다. 이 판단을 테스트로 못박았다 — **릴레이 목록에서 키가 빠지면
테스트가 먼저 깨져** 판단을 다시 하게 만든다.

지적의 남은 절반은 사실이다: 크기에는 `[`/`]` 가 있지만 불투명도·외곽선 굵기에는
포인터 말고 길이 없다. 이 PR 이전에도 그랬고, 열어 주려면 오버레이→호스트 포커스
상태 채널이 먼저 필요하다.

## 가짜 DOM 을 표준에 맞춰야 했다

런타임이 `style.setProperty` 라는 표준 API 를 쓰기 시작하자 가짜 DOM 3곳
(`mpv-fabric-overlay-runtime` / `fabric-drawing-pilot-integration` /
`drawing-sync-remote-overlay`)의 `style` 이 순수 객체라 **`prepare()` 자체가
실패**했다. 가짜 쪽에 `setProperty`/`getPropertyValue`/`removeProperty` 를 넣었다.

새 표준 DOM API 를 쓸 때는 이 세 파일을 함께 볼 것.

## 다시 밟은 함정

호스트 CSS 는 JS **템플릿 리터럴** 안이다. 주석에 백틱을 쓰면 `SyntaxError` 가
난다. 직전 라운드 DEVLOG 에 적어 놓고 이번에 또 밟았다.

Python 힙독으로 **여러 줄 정규식 리터럴**을 쓰면 깨진다는 것도 다시 확인했다.
문자열 `indexOf`/`includes` 검사로 우회했다.
