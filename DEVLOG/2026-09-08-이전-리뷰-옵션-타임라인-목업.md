# 이전 리뷰 옵션과 타임라인 구성 목업

> 이 목업을 승인받아 [실제 앱 통합](2026-09-08-이전-리뷰-타임라인-통합.md)을 완료했다. 아래는 목업 제작 시점의 기록이다.

작성일: 2026-09-08

상태: 최신 시연 피드백에 따른 인터랙티브 구성 목업. 아래 옵션 팝업과 버전별 타임라인은 아직 실제 Electron 화면에 통합하지 않았다. 실제 앱의 직전 구현 상태는 [이전 리뷰 확인 구현](2026-09-08-이전-리뷰-확인-구현.md)에 기록한다.

## 최신 요구사항

- 합쳐 보기만 제공한다는 직전 결정을 철회하고 분리/합쳐/팝업 보기를 다시 제공한다.
- 버전 선택과 보기 옵션이 댓글 공간을 과하게 차지하지 않도록 작은 팝업으로 옮기는 방안을 검토한다.
- 이전 리뷰를 켰을 때 타임라인에서도 현재 댓글과 출처를 구분할 수 있어야 한다.
- 원본의 미해결/해결 상태를 이어받는다. 확인 전/반영 확인 같은 별도 검수 상태는 다시 도입하지 않는다.
- 이전 리뷰가 있을 때만 진입 버튼을 표시하고, 같은 버튼으로 켜고 끈다는 기존 요구는 유지한다.

## 제안과 조작 가능한 내용

댓글 패널에는 높이 40px의 한 줄을 둔다. 이전 리뷰 토글, 선택한 버전/개수, 옵션 버튼만 표시한다. 옵션을 눌렀을 때 320px 팝업에서 버전 다중 선택, 세 가지 보기 방식, 타임라인 표시, 일괄 이어받기를 조작한다. 팝업을 닫으면 목록 공간을 차지하지 않는다.

분리 보기는 현재 댓글 아래에 이전 리뷰 구역을 둔다. 합쳐 보기는 시간순으로 정렬한다. 팝업 보기는 이동/크기 조절 가능한 패널로 표현한다. 목업의 팝업은 브라우저 안에 있으며 실제 별도 OS 창 구현은 포함하지 않는다.

타임라인은 현재 댓글 행 아래에 선택한 이전 버전별로 얇은 행을 둔다. v4는 노란색, v3는 파란색, v2는 보라색, v1은 청록색으로 구분하며 이름도 함께 표시한다. 미해결은 채운 표식, 해결은 체크가 있는 빈 표식이다. 같은 시간의 여러 버전 리뷰가 겹쳐 클릭하기 어려운 문제를 피한다. 리뷰나 표식 클릭 시 같은 시간으로 이동하고 해당 카드와 표식을 강조한다. 현재 영상 길이 밖의 리뷰는 `범위 밖 N`으로 표시하며 임의로 끝 프레임에 배치하지 않는다.

목업은 실제 `ReviewCarryoverManager`와 `createPreviousReviewSources`를 사용하고 가상 데이터만 메모리에 보관한다. v3/v2/v1은 30fps, 현재 v4는 24fps/12초다. 새로고침 또는 시연 초기화로 돌아갈 수 있다. 사용자 리뷰 파일과 프로필은 수정하지 않는다. 원본 해결 상태를 계승하는 매니저 동작은 직전 구현에 이미 포함되어 있어 재사용했다.

## 검증 결과

- JS와 서버 `node --check`: 둘 다 exit 0.
- 기존 `node --test scripts/tests/review-carryover.test.js`: 7 pass, 0 fail, 0 cancelled, exit 0. 원본 상태 계승, 저장/재로드, 중복 방지, 병합 및 호환 데이터 보존을 확인한다.
- 인앱 브라우저에서 직접 클릭: v2/v3 다중 선택, 분리/합쳐/팝업 전환과 패널 복귀, 이전 리뷰 전체 토글, 타임라인만 별도 숨김/복구, Escape로 옵션 닫기를 확인했다.
- 해결된 v3 타임라인 표식 클릭: `00:00:07:12`, 180프레임으로 이동. 16초 범위 밖 리뷰 클릭 후 위치가 유지되고 안내가 표시됐다.
- v2/v3 일괄 이어받기: 미해결 4개와 해결 3개가 그대로 유지됐다. 해결 항목 하나를 미해결로 바꾸자 카드, 타임라인, 미해결 개수가 함께 갱신됐다. 토글을 껐다 켠 뒤에도 유지됐다.
- 1315×1270 화면 스크린샷 확인: 가로 넘침 없음, 닫힌 옵션 바 높이 40px. 브라우저 error 로그 0개.
- 이번 목업에 대한 실제 Electron 통합, 별도 OS 창, 배포 빌드, 다중 PC 협업 검증은 수행하지 않았다.

## 실제 통합 시 고려할 사항

현재 `Timeline.renderCommentRanges()`는 현재 댓글 트랙을 비우고 드래그/범위 조절 핸들을 생성한다. 이전 리뷰는 별도의 읽기 전용 행으로 렌더링하고 출처 키를 사용해야 한다. 원본 댓글을 현재 CommentManager에 주입하지 않으며, 클릭은 기존 FPS 변환/범위 검사와 카드 선택 경로에 연결한다. 토글/필터/버전 선택/상태 변경에 맞춰 행을 갱신하고 영상 전환 시 제거한다. 재생목록/컷 목록의 합산 타임라인 문맥과 오래된 비동기 응답 차단도 기존 앱 경계를 유지한다.

세 버전 이상 또는 댓글이 많은 실제 작업물에서는 행 높이와 스크롤, 같은 버전 안에서 겹치는 표식의 펼침 동작을 추가로 확인해야 한다. 이번 목업은 출처 구분과 공간 배치에 대한 시안이며 이 통합 검증을 대신하지 않는다.
