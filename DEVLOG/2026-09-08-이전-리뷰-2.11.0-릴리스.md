## 범위와 버전

- 사용자가 실제 시연 후 PR 리뷰, 머지, 빌드와 공유드라이브 배포까지 승인했다. Slack 안내 게시 요청은 없다.

- 기능/UI/실제 Electron 조작 근거는 [타임라인 통합 기록](2026-09-08-이전-리뷰-타임라인-통합.md)을 참조한다.

## 릴리스 진행

PR은 최종 head에 대한 Codex 명시적 완료 신호와 미해결 지적 없음을 확인한 뒤 머지한다. 정확한 merge SHA의 깨끗한 별도 체크아웃에서 `npm run build`를 실행한다. 기존 배포는 백업하고 staging을 검증한 뒤 교체한다. 최종 소스/배포 전체 파일 상대 경로·바이트·SHA-256 비교를 별도 배포 증거에 기록한다.

실제 여러 PC의 동시 협업과 각 팀원 PC 동기화 완료는 이번 자동 검사로 확인할 수 없다. 기존 UI 시연의 영상 이동은 HTML 재생 엔진에서 검증했다.
