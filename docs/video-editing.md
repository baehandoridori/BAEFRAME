# 간단한 영상 편집

리뷰 화면의 **영상 편집** 버튼으로 편집창을 엽니다. 여러 영상을 자르고 이어 붙인 뒤, 정지 구간과 그림을 더해 MP4로 저장할 수 있습니다.

## 처음 영상 만들기

1. 오른쪽 **프로젝트**에서 화면 비율과 초당 프레임 수(FPS)를 정합니다. 릴은 **세로 9:16**을 선택합니다. 프레임 수는 영상을 가져오기 전에 정하고, 화면 비율은 그림을 그리기 전에 정합니다.
2. **영상 가져오기**로 사용할 영상을 선택합니다. 여러 파일을 한꺼번에 가져올 수 있습니다.
3. 아래 타임라인에서 컷을 선택합니다. 컷을 끌면 들어갈 위치가 표시되고, 놓으면 순서가 바뀝니다. **← / →** 버튼으로도 이동할 수 있습니다.
4. **C**로 자르기 도구를 켜고 컷 안의 원하는 위치를 클릭하면 그 프레임에서 나뉩니다. **V**로 선택 도구로 돌아옵니다. 재생 위치에서 나누려면 **분할** 버튼을 누릅니다. 불필요한 컷은 **컷 삭제**로 제거합니다. 컷 양끝은 오른쪽 **앞에서 제거 / 뒤에서 제거**에 초를 입력하고 **자르기 적용**으로 줄입니다.
5. **저장**으로 편집 프로젝트를 보관하고, **MP4 내보내기**로 완성 영상을 만듭니다.

## 영상 멈추기

원하는 프레임으로 이동한 뒤 오른쪽 **정지 프레임**의 **길이 (초)**를 입력합니다.

- **시간 추가**: 현재 프레임을 설정한 시간만큼 보여준 뒤 원래 영상을 이어 재생합니다. 전체 영상 길이가 늘어납니다.
- **현재부터 대체**: 현재 위치부터 설정한 길이만큼 정지 화면으로 바꿉니다. 전체 길이는 유지됩니다. 선택한 컷 안에 들어가는 길이만 사용할 수 있습니다.

**현재 화면으로 정지 구간 만들기**를 누르면 정지 컷이 생깁니다. 정지 구간에서는 원본 소리를 끄고 배경음악은 계속 재생합니다. 정지 컷에도 그림을 그릴 수 있습니다.

## 그림과 레이어

그림은 선택한 컷에 속합니다. 컷을 이동하면 함께 이동하며, 컷을 나눈 뒤에는 각각 독립적으로 수정할 수 있습니다.

왼쪽 도구 막대에서 현재 도구를 선택합니다. 활성 도구는 강조되고 미리보기 아래에도 이름이 표시됩니다. 도구 설정 행의 높이는 바뀌지 않으며, 선택 도구에서는 획 전체/부분과 사각/라쏘를 같은 행에서 고릅니다.

- **펜 / 선택 / 지우개 / 선 / 사각형 / 화살표**: 기존 드로잉 엔진을 사용합니다. 아래 도구 설정에서 색·굵기·불투명도를 조절합니다.
- **● 키프레임**: 현재 그림을 바탕으로 새 그림 시점을 만듭니다.
- **○ 빈 키프레임**: 빈 그림 시점을 만듭니다.
- **그림 유지 +1F**: 기존 드로잉의 프레임 유지 동작을 적용합니다. 영상 정지는 오른쪽의 정지 구간 버튼으로 만듭니다.
- **+ 레이어**: 그림을 나누어 작업합니다. 레이어를 선택하거나 표시를 켜고 끌 수 있습니다.

타임라인에는 선택한 컷의 드로잉 레이어만 펼쳐집니다. **드로잉 접기**로 공간을 확보하고, **선택 컷** 보기나 확대 슬라이더로 키프레임 위치를 확인합니다. 재생 중에는 그리기를 잠가 영상과 그림의 시간을 맞춥니다.

## 화면 이동과 타임라인 확대

- **H** 도구 또는 마우스 가운데 버튼으로 미리보기와 타임라인을 끌어 이동합니다. 영상과 그림은 함께 움직이며 저장되는 그림 좌표는 바뀌지 않습니다.
- 미리보기의 **화면 맞춤 / 50% / 100% / 150% / 200%**로 배율을 정합니다. 숫자는 완성 영상의 픽셀 크기를 기준으로 합니다. **맞춤**은 이동과 확대를 초기화합니다.
- 타임라인의 **+ / −**, 확대 슬라이더 또는 **Ctrl+휠**로 확대합니다. 시간 눈금은 초 단위에서 프레임 단위까지 바뀝니다.
- 타임라인 아래 작은 전체 범위 표시에서 표시 창을 끌어 다른 구간으로 이동합니다. **맞춤**으로 전체 영상 길이를 다시 볼 수 있습니다.
- 타임라인 위 눈금에서 재생 위치를 드래그합니다. 처리 중에는 직전 화면을 유지하고, 준비된 영상과 그림을 함께 표시합니다.

## 소리와 출력

컷별 **원본 소리**를 0%로 낮추면 음소거됩니다. **음악 가져오기**로 배경음악 하나를 추가하고 음량을 정할 수 있습니다. 화면 맞춤은 **전체 보이기** 또는 **화면 채우기**를 선택합니다.

MP4에는 컷 순서, 정지 구간, 그림, 원본 소리와 배경음악이 함께 들어갑니다. 출력 중 **출력 취소**를 누를 수 있습니다. 출력이 정상 완료된 뒤에만 지정한 결과 파일을 반영합니다.

## 저장과 단축키

편집 내용은 `.bedit` 파일에 저장합니다. 원본 영상 경로를 참조하므로 프로젝트를 옮길 때 원본 파일도 필요합니다. 기존 리뷰 `.bframe`과 원본 영상을 덮어쓰지 않습니다. 저장하지 않은 상태에서 창을 닫으면 확인창이 표시됩니다.

| 단축키 | 동작 |
| --- | --- |
| V | 선택 도구 |
| C | 자르기 도구, 컷을 클릭한 위치에서 분할 |
| H | 화면 이동 도구 |
| B | 펜 도구 |
| E | 지우개 도구 |
| Space | 재생 / 일시정지 |
| ← / → | 이전 / 다음 프레임 |
| + / − | 타임라인 확대 / 축소 |
| Ctrl+S | 저장 |
| Ctrl+Z | 실행취소 |
| Ctrl+Shift+Z 또는 Ctrl+Y | 다시실행 |

입력칸을 편집할 때는 영상 단축키가 동작하지 않습니다.

V·C·H는 [Adobe의 기본 도구 단축키](https://helpx.adobe.com/be_en/premiere/desktop/get-started/keyboard-shortcuts/default-keyboard-shortcuts.html)를 참고했습니다. B·E는 BAEFRAME 드로잉 작업을 위한 키입니다.

## 현재 범위

이번 버전은 영상 한 줄과 배경음악 하나를 사용하는 기본 편집입니다. 다중 영상 트랙, 전환 효과, 자막 도구, 속도 변경, 음악 구간 편집, 원본 파일 재연결은 후속 범위입니다. 기존 리뷰의 그림을 자동으로 가져오지는 않으며, 편집창에서 제작용 그림을 만듭니다.

편집창은 Windows 데스크톱용입니다. 모바일 보고서 열람과 모바일 영상 편집은 별도 기능입니다. 미리보기는 실제 영상 프레임을 기준으로 그림을 맞추며, 서로 다른 원본으로 넘어갈 때 디코더 준비에 따라 잠깐 대기할 수 있습니다. 완성 MP4는 고정된 출력 프레임 수로 생성합니다.
