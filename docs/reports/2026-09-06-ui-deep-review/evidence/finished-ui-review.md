# 보강판 2 독립 검토

2026-09-06. 사용자가 BAEFRAME 기본 앱과 BEditer 양쪽의 완성 UI 예시를 요구해 10장을 보강했다.

- 네 시안: 기본 리뷰 / 드로잉 리뷰 / 기본 편집 / 세로 편집. 동일 해상도와 공통 셸, 영상·댓글·선택 속성을 채웠다.
- 독립 읽기 전용 검토: 기본 앱 업무가 독립된 두 완성 화면과 기능 대응표로 다뤄졌으며 요구 충족. 80F/288F 리뷰, 편집72F/컷로컬24F/원본48F, 노출12F 계산 일치.
- 기존 배경음악을 새 기능으로 오분류한 초안을 수정했다. 기존 importMedia('audio'), project.music, 미리듣기와 amix 출력은 유지하고 파형·세부 오디오 UI만 확장 제안이다.
- 영상 클립 수치 변형은 현 contain/cover와 구별해 확장 제안으로 명시했다. 선택 그림의 수치 편집도 확장 제안 표기를 유지했다.
- 리뷰 노출 키의 마름모를 채운 점/빈 점으로 통일해 편집기와 공통 드로잉 문법을 적용했다.
- 직접 시각 검토에서 BEditer 영상 행 내부로 다른 행이 잘못 들어간 제작 마크업을 수정했다. 최종 영상58px/그림32px/소리32px, 레이블152px.
- 기본/드로잉 리뷰의 고정40px문맥바로 영상 bounds 일치. 두 번의 animation frame 뒤 캡처해 글자 paint 누락 방지.

실제 앱 코드 수정, 실제 제품 기능 테스트, Windows DPI, 최종 출력 영상, 추가 Sites 브라우저/모바일 QA는 수행하지 않았다. 시안 HTML의 렌더·경계·이미지 로딩과 정지 PNG를 검토했다.
