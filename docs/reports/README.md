기준은 편집기 좌표·도구·타임라인 개선을 반영한 `5d1cb89`다. 기존 리뷰창과 새 편집창을 함께 다루며, 14장·26개 항목에 문제·영향·원인·해결·부작용·완료 기준을 정리했다. 현재 화면27개를 수집했고 본문에는 대표17개+공식참고6개+미구현제안4개를 넣었다. 공식5제품15문서를 비교하고 과제6개와 단계별 구현 기준을 제안했다.

이번에는 앱 코드를 변경하지 않았다. 실제 앱/renderer 관찰과 시험용 IPC, 현재 코드, 타사 공식 자료, 설계 판단을 구분했다. 기존 UX 원본57개의 SHA-256을 이전 보존 worktree에서 재검사했으며 불일치는0개다. 게시본은 원시 로그·테스트 프로필·합성 영상 없이 본문과 이미지로 구성된다. Sites 페이지의 추가 브라우저/모바일 기기 QA는 수행하지 않았고 문서 구조·이미지·출처·앵커·해시 및 개발서버HTTP200을 확인했다.

## 검증된 문제와 제안의 구분

보고서는 총 19개 개선 항목(P1 9개, P2 9개, P3 1개)을 다룬다. 우선순위는 근거 수준과 다르다. 모든 항목을 실제 Windows 화면에서 재현한 것은 아니므로 각 항목의 확인 방법과 제한을 함께 읽는다.

| 근거 수준 | 해당 항목 | 판단 범위 |
|---|---|---|
| 실제 화면·파일·측정에서 확인 | I01 반복 대기, I02 댓글 진입 시 그림 미표시, I05 댓글 초안 유실, I08 전환 중 표시 불일치, I10 패널에 의한 조작 영역 밀림 | 별도 테스트 프로필의 앱·합성 영상·DOM·파일 측정에서 관찰한 결과다. |
| 함수·모듈 실행에서 재현 | I03 웹 V3 그림 표시, I04 공유 안내, I06 늦은 전환, I07 정지·실패 구분, I09 썸네일, I12 필터 이동, I16 창 닫기, I17 재생목록 저장, I18 이미지 붙여넣기 | 실제 코드의 실패 조건을 확인했으며 일부 IPC·클립보드·비동기 경계는 모의 처리했다. 실제 수신자·두 PC·OS 클립보드 전체 검증으로 확대하지 않는다. |
| 이미지 처리 함수의 실제 픽셀 확인 | I19 투명 이미지 배경 | 처리 전후 픽셀을 비교했다. 실제 OS 클립보드 동작 검증은 포함하지 않는다. |
| 소스·정책·가시성 점검 | I11 단축키·레이어 발견성, I13 재생·리뷰 진입 규칙, I14 저장·연결·반영 상태 | 구현된 정책과 표현의 혼란을 분석한 항목이다. I13은 실제 앱 관찰도 포함하지만 모든 동작을 오류로 분류한 것은 아니다. |
