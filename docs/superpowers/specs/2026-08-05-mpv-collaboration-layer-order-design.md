# mpv 협업 UI 레이어 순서 회귀 수정 설계

## 배경

BAEFRAME의 mpv 재생 화면은 Chromium 화면과 분리된 Windows 네이티브 창이다. 따라서 일반 DOM의 `z-index`만 높여서는 Liveblocks 커서, 현재 작업 인원, 재생 동기화 상태를 mpv 위에 안정적으로 표시할 수 없다.

PR #172에서는 이 문제를 해결하면서 `.collaborators-indicator`와 `.playback-sync-panel`을 mpv 차단 표면으로 등록했다. 협업 시작 시 재생 동기화 패널이 자동 표시되면 작은 패널 하나 때문에 mpv 호스트 전체가 숨겨지고, 결과적으로 정상 재생 중인 영상이 검은 화면으로 보이는 회귀가 생겼다.

## 목표 동작

- 협업 여부와 관계없이 mpv 영상은 계속 재생되고 화면에 표시된다.
- Liveblocks 원격 커서, 현재 작업 인원, 동기화 상태는 mpv보다 위의 표시층에서 함께 보인다.
- 협업 UI의 클릭, 호버, 접기, 닫기, 드래그 동작은 기존과 동일하게 유지한다.
- 모달처럼 영상 전체를 실제로 대신해야 하는 화면만 mpv 호스트를 일시적으로 숨길 수 있다.
- 접혀 있거나 투명하거나 조상에 의해 잘린 요소는 mpv 차단 표면으로 오판하지 않는다.

## 검토한 방법

### 1. 협업 UI를 mpv 차단 표면으로 유지

작은 협업 UI가 표시될 때마다 mpv 전체를 숨기는 현재 방식이다. 구현은 단순하지만 영상 재생 화면이 사라지므로 목표 동작에 맞지 않는다.

### 2. 협업 UI 등록만 제거

검은 화면은 즉시 사라지지만, mpv가 협업 UI를 다시 가리므로 원래 문제가 재발한다.

### 3. 협업 UI를 mpv 상단 미러 레이어로 전환

선택한 방식이다. mpv 호스트는 계속 보이게 두고, 협업 UI의 보이는 모양을 기존 투명 오버레이 창에 같은 위치로 복제한다. mpv 호스트와 수동 상태의 오버레이 창은 마우스 입력을 아래의 메인 화면으로 통과시키므로, 사용자는 위에 보이는 복제 UI를 보면서 기존 DOM UI를 그대로 조작할 수 있다.

## 설계

### 표면 분류

`renderer/scripts/modules/mpv-surface-policy.js`의 표면 정책을 다음처럼 구분한다.

- `.collaborators-indicator`: `BLOCK`에서 제거하고 `HTML_MIRROR`로 이동
- `.playback-sync-panel`: `BLOCK`에서 제거하고 `HTML_MIRROR`로 이동
- 원격 커서: 현재의 전용 미러 경로 유지
- 모달, 댓글 입력창처럼 미러만으로 완전한 상호작용을 보장할 수 없는 표면: 기존 `BLOCK` 정책 유지

이 분류로 협업 상태 표시는 영상 위에 보이지만 mpv 호스트 가시성에는 영향을 주지 않는다.

### 표시 흐름

1. Liveblocks 상태가 바뀌면 메인 DOM의 협업 인원·동기화 UI가 갱신된다.
2. 기존 미러 관찰자가 변경을 감지한다.
3. 보이는 요소의 위치와 계산된 스타일을 직렬화해 mpv 투명 오버레이 창에 전달한다.
4. 투명 오버레이 창이 복제 UI를 mpv 위에 표시한다.
5. 마우스 입력은 기존처럼 메인 DOM으로 통과해 원래 이벤트 핸들러가 처리한다.

### 실제 가시성 판정

`isMpvSurfaceVisiblyOverlappingHost()`는 요소 자체뿐 아니라 조상 체인을 확인한다.

- 조상 중 `display: none`, `visibility: hidden`, `opacity: 0`이 있으면 보이지 않는 것으로 처리한다.
- `overflow: hidden`, `clip`, `auto`, `scroll` 조상은 실제 잘린 사각형을 계산한다.
- 잘린 결과의 너비나 높이가 0이면 mpv와 겹치지 않는 것으로 처리한다.

이를 통해 높이 0·투명 상태인 협업 플렉서스 패널의 내부 요소가 독립적으로 보인다고 오판하는 문제를 막는다.

### 실패 시 원칙

협업 UI 미러 갱신이 일시적으로 실패해도 mpv 영상은 숨기지 않는다. 이 경우 영상 재생을 우선 유지하고 다음 상태 변경이나 강제 동기화에서 협업 UI 미러를 다시 갱신한다.

## 테스트

- 협업 인원 표시와 재생 동기화 패널이 `BLOCK`이 아닌 `HTML_MIRROR`로 분류되는지 검증한다.
- 표시된 동기화 패널이 영상과 겹쳐도 mpv 호스트 숨김 조건이 되지 않는지 검증한다.
- 협업 UI가 오버레이 상태에 직렬화되는지 검증한다.
- 투명한 조상과 높이 0의 잘림 조상 내부 요소가 가림 표면으로 판정되지 않는지 검증한다.
- 실제 mpv 관련 전체 테스트와 패키지 빌드를 통과시킨다.
- 배포본에서 협업 연결 상태로 영상 재생, 커서, 작업 인원, 동기화 신호가 동시에 보이는지 확인한다.

## 완료 조건

- 협업 시작 전후 모두 영상이 검게 변하지 않는다.
- mpv 재생 중 원격 커서·작업 인원·동기화 신호가 영상과 동시에 표시된다.
- 기존 댓글·그리기·모달 오버레이 동작에 회귀가 없다.
- PR 리뷰와 머지 후 `2.0.2-beta`보다 높은 버전으로 빌드한다.
- 공유 드라이브 테스트 버전 배포본과 로컬 빌드의 전체 파일 해시 차이가 0이다.
